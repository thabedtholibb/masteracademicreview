# Code Of Conduct

This project is used by researchers, students and reviewers from many fields,
countries and career stages. We want taking part to be respectful and
welcoming for everyone, regardless of age, body size, disability, ethnicity,
gender identity and expression, level of experience, education,
socio-economic status, nationality, personal appearance, race, religion, or
sexual identity and orientation.

This code is adapted from the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected Behaviour

- Be kind and patient, especially with people new to evidence synthesis or to programming.
- Critique methods, code and evidence, not people.
- Back disagreements with sources; accept correction when the evidence is against you.
- Credit other people's work and ideas.
- Respect research integrity: never ask for, or help with, fabricated data,
  invented references, or misrepresented results.

## Unacceptable Behaviour

- Harassment, insults, or derogatory comments, in public or in private.
- Sexualised language or imagery, and unwelcome attention.
- Publishing someone's private information without explicit permission.
- Sustained disruption of discussions, issues or reviews.
- Using the project to promote predatory publishing or paper mills.

## Scope

This code applies in all project spaces (issues, pull requests, discussions)
and when someone represents the project in public.

## Reporting And Enforcement

Report unacceptable behaviour privately to the maintainer through the contact
details on the maintainer's GitHub profile (the repository owner). Reports are
handled confidentially. The maintainer may remove comments, commits or
contributions that break this code, and may temporarily or permanently ban a
participant, depending on the severity:

1. **Correction**: a private, written warning explaining the problem.
2. **Warning**: a warning with consequences for continued behaviour.
3. **Temporary ban** from interaction with the project.
4. **Permanent ban** for a pattern of violations or severe harassment.
